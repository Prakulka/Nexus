Step 1 of 9 · Registration & Validation

Nexus tool intake ALL TOOLS

Every tool — MCP server, Plugin, or Agent Skill — starts here. Design review cannot happen before intake, so this is the first task in the flow.

Is this tool for Advanced Work (FluxV4 / inner-grain)?
This one answer decides which ADV WORK tasks below become required. Flip it to preview.

📋 Intake form

  • Tool type: MCP / Plugin / Agent Skill
  • Name, owners, ICM, business justification
  • Advanced Work? — Yes / No (gates the inner-grain tasks)
Applies to: ALL tools
Required for every onboarding. The "Advanced Work?" answer is what turns the purple tasks on or off downstream.
